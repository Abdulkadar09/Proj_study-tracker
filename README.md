# Study Time Tracker

A minimal study tracker that records:
- what subject was studied
- when it was studied
- how long it lasted

## Setup

1. Install dependencies:

```bash
npm run install-all
```

2. Run the app in development:

```bash
npm run dev
```

3. Open it locally in your browser:

- `http://localhost:5173` for the React frontend
- `http://localhost:3001` for the API server

## Production deployment

The app is built to run as a single Node service. The frontend is compiled into `client/dist`, and the Express server serves it from there.

### Run in production mode locally

```bash
npm start
```

Then open:

- `http://localhost:3001`

### Share with friends on the same network

1. Run `npm start`.
2. Get your machine IP address, for example `192.168.1.20`.
3. Make sure port `3001` is open in your firewall.
4. Share this URL:

```text
http://192.168.1.20:3001
```

### Temporary internet access with ngrok

If you want friends to access it over the internet without hosting it remotely:

```bash
npx ngrok http 3001
```

Then share the public URL generated by ngrok.

## Remote deployment

This repo is ready for deployment to any Node hosting provider.

Recommended hosts:
- Render
- Railway
- Fly.io
- Heroku

### Deployment steps

1. Push the repository to GitHub.
2. Connect the repo to your host provider.
3. Configure the start command:

```bash
npm start
```

4. Make sure the hosting service sets `PORT` automatically.

### Environment configuration

The frontend uses `VITE_API_BASE` at build time to call the API.

- For same-origin deployments (recommended), leave `VITE_API_BASE` empty.
- For separate backend hosting, set it to your API URL.

Example:

```env
VITE_API_BASE=https://your-app.example.com
```

## Notes

- `client/.env.development` is configured for local dev (`http://localhost:3001`).
- `client/.env.production` is intentionally left blank so the production frontend calls the same origin by default.
- The server already supports `process.env.PORT` for hosted environments.

## Project structure

- `client/` — React + Vite frontend
- `server/` — Express backend with SQLite
- `study.db` — SQLite database file created at runtime
